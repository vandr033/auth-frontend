# Vendored fonts

These WOFF2 files come from the Google Fonts CSS API and are committed so production builds do not fetch fonts. The files in this directory are the Latin subsets used for preload; `non-latin.css` and `assets/` preserve the other upstream Unicode subsets and ranges. The corresponding SIL Open Font License 1.1 notices are in `public/fonts/licenses/` and are copied into the production image with `public/`.
